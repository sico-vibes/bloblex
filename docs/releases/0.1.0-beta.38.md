# Bitbots 0.1.0-beta.38

Fixes and new features after beta.37: scheduled tasks with images, one resizable companion for every look, words while you dictate, and Whistle, a small dictation engine you can download. If you run beta.32 or later, this version downloads by itself and shows **Restart to update** in the top bar.

## New

- **Scheduled tasks.** A task's **When** can be Now, Once at a date and time, or Repeat on a schedule, using the same scheduler as automations. The dialog shows the next run times. A scheduled run works on its own like an automation: it never bypasses approvals and it stops at the task's time limit. Tasks run only while Bitbots is open and the computer is on and awake; a run missed by more than five minutes is skipped, not run late.
- **Images on tasks.** Attach images to a task by choosing, pasting or dropping them. When you give the Manager images and ask it for tasks, it can attach them to the drafts. The images go to the bot when the task runs.
- **Every task field is editable**, including the project, the bot, the time limit and an estimate.
- **Whistle dictation (test).** A 17 MB on-device dictation engine from Cactus, for seven languages, which you can download in Settings › Speech next to the existing models. On Windows it runs Cactus's own engine program, which is checked against a pinned fingerprint before every use. Parakeet stays the default. This is a first version: if Whistle does not transcribe, please tell us.

## Changed

- **One companion for every look.** Frost and Stone now use the companion from Haze: your bots on the left and the open conversation on the right, with approvals, activity and settings in the same place. Each look keeps its own bots; the status gradient stays in Haze.
- **Resize the companion.** Drag any edge or corner to resize it; it remembers its size and stays on top. **Make larger** in its header grows it, and Settings › Reset size puts it back. The Compact, Comfortable and Tall height setting is gone.
- **Words while you dictate.** With Parakeet, words now appear about every second while you speak, and a sentence is finished after a short pause. Cloud dictation cannot show words as you speak, so it now says that words appear when you stop.
- Conversation branches now hang from below their parent in the conversation list.

## Fixed

- **Tasks page showed `sqlite: no such table: tasks`** on databases from before the Tasks page. The task tables are now added when Bitbots opens an older database.
- **The companion could not open a bot with no conversation.** You can now pick such a bot and send it a first message, as in the main window.
- **Menus inside dialogs** (such as Project in the task dialog) opened inside the dialog and stretched it. They now float above it.
- **Message buttons** (time, copy, reply, reactions) now line up with the middle of the message.
- **Automation schedules always said "No upcoming runs".** They now show the next run times.

## Installation

Running beta.32 or later: wait for **Restart to update**, or check now in Settings › Updates. Older versions: download `Bitbots_0.1.0-beta.38_x64-setup.exe` and verify it against `SHA256SUMS.txt`. The installer is not Authenticode-signed (Windows may warn).
