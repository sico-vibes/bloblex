# Bitbots 0.1.0-beta.32

Fixes from the owner's beta.31 review, slash commands, and **automatic updates**. **Install
this version by hand once**: it carries a new update key, and from here on Bitbots downloads
newer versions by itself and asks you to restart.

## New

- **Automatic updates.** Bitbots checks for a newer version shortly after it starts and every
  four hours, downloads it in the background, and shows **Restart to update** in the top bar
  when it's ready ("Downloading update · 42%" while it downloads). Nothing installs until you
  click it. Turn it off in Settings › Updates ("Download updates automatically").
- **Slash commands.** Type `/` in a message box for a menu:
  - **Actions:** `/plan`, `/new`, `/model`, `/effort`, `/rename`, `/export`, `/help`.
  - **Skills:** any skill from Settings › Skills that's on for this bot. Picking one tells the bot
    to load it for that message.
  - **Manager:** `/interview`, `/onboard`, `/team`, `/status`, `/playbook` and `/remember`, only
    in the Manager's conversation.

## Fixed

- **The phone page opens instead of downloading a file**, for both Tailscale and Direct.
- **"The coding agent is not available" after signing in again.** When a stored Claude, Codex
  or OpenCode session can't be resumed, Bitbots now starts a fresh one and says the earlier
  context wasn't carried over, instead of failing.
- **The app no longer jumps between bots by itself** after you delete a conversation or archive
  a bot, and no longer adds unread dots to conversations you didn't leave unread.
- Tooltips are no longer cut off by the edge of a panel or the Settings window.
- Provider logos in the sidebar sit on the same line as the bot's name, closer to it.
- The bot-to-bot conversation badge's shadow is no longer clipped by the top bar.

## Verification

- Rust workspace excluding the desktop crate: 723 tests passed; clippy clean.
- Desktop crate library: 64 tests passed.
- Desktop typecheck and 1136 tests pass; the main, remote and preview web builds succeed.
- Browser preview checks for the sidebar logos (centred, 5 px gap), tooltips clamped inside the

## Installation

Download `Bitbots_0.1.0-beta.32_x64-setup.exe` and verify it against `SHA256SUMS.txt`. The
installer is not Authenticode-signed (Windows may warn). This release is signed for the updater
with a new key and published to the beta update channel, so later versions install themselves.
Versions before beta.32 can't update to it automatically.
