# Bloblex 0.1.0-beta.8

## Changes

- Add provider quota meters for Codex, Claude Code OAuth plans, and OpenCode Go.
- Show a compact primary-window meter for each supported provider in the shell; the existing Usage sheet lists available windows and reset times.
- Poll quota sources in the background, retain the last successful normalized snapshot on failures, and keep quota separate from reported token analytics.
- Reuse CLI-owned authentication for quota checks. Existing tokens and keys are read transiently in process memory; Bloblex does not refresh or modify CLI auth, persist or log credentials, or forward credentials/raw responses to the renderer.
- Keep generic OpenCode providers out of the account quota meter; OpenCode support here is OpenCode Go only.

## Verification

- Daemon, storage, Codex app-server, desktop typecheck, full Vitest, mounted quota UI, and production build gates pass for this source tree.
- Isolated daemon quota fetches succeeded with Claude Code 2.1.291, Codex codex-cli 0.160.1, and OpenCode 1.18.34. The smoke used a temporary database and sent no prompts; retained output contains only provider/status/window-presence metadata.
- Native UI behavior and a clean-machine installer pass remain unverified.
