# Bitbots 0.1.0-beta.50

This release fixes a sidebar mistake and a noisy startup warning, and adds a Projects view. If you run beta.32 or later, this version downloads by itself.

## Added

- **Projects view.** The sidebar has a Bots and Projects switch. Projects lists each project with its bots and their latest three conversations.
- **Cursor CLI and Grok CLI.** Bitbots detects them when they are installed. The launch commands come from the vendors' documentation and have not been tried on a real install.

## Changed

- The startup warning is now a short count. Show details opens the full list, and the same wording no longer appears twice.
- Gemini CLI is no longer looked for.
- The Companion switch has moved out of the sidebar. It is still in Settings › Companion.
- Projects can be collapsed in the conversations list.

## Fixed

- Opening a conversation no longer shows it as updated just now.

## Installation

Running beta.32 or later: wait for **Restart to update**, or check now in Settings › Updates. Older versions: download `Bitbots_0.1.0-beta.50_x64-setup.exe` and verify it against `SHA256SUMS.txt`.
