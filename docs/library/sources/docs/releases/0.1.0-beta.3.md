# Bloblex 0.1.0-beta.3

## Changes

- Blob editor is one page: the blob at the top, then appearance, profile, model, permissions, details, conversations, usage and archive.
- Favourite blobs and pinned projects or conversations get their own sections at the top of the sidebar (right-click a blob, project or conversation).
- The sidebar tree branches bend into each project and conversation, and the selected conversation is shown in bold instead of a second box.
- The companion opens at a centred spot a little above the bottom of the screen, plays the full welcome greeting, rests, then shrinks to its compact bar. Moving the mouse away no longer cuts the greeting short.
- In the compact companion the approval badge sits next to the blob name.
- Companion colours and switches match the desktop app; the details tabs are centred.

## Known limits

- Unit tests use fake processes. Not yet verified against live provider command line tools or on a clean machine.
- The installer is not code-signed, so Windows may show a SmartScreen warning.
- Windows only. WSL launch is not usable yet.
