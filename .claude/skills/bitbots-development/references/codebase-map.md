# Codebase map

Last reviewed: 2026-10-22 (the task board, the look list and the settings pages were re-checked against the code). When you add or move something listed here, update this file.

## Repository root

- `AGENTS.md` (how the project is run; read the top amendments), `docs/design/design-system.md` (design rules), `docs/design/product.md`, `README.md`, `docs/operations/session-handoff.md` (latest state at the top), `docs/legal/third-party-notices.md` (add a line for every new bundled font or library).
- `apps/desktop/`: the desktop app (npm workspace `@bloblex/desktop`).
- `crates/`: Rust workspace (`Cargo.toml` `[workspace.package].version` is the app version, with `package.json`, `apps/desktop/package.json` and `apps/desktop/src-tauri/tauri.conf.json`).
- `scripts/`: `release-windows.ps1` (signed release), `bundle-windows.ps1` (`npm run desktop:bundle`), `stage-daemon.mjs`, `dev-windows.ps1`, `docs-library.mjs` (`npm run docs:build|docs:check|docs:serve`).
- `docs/`: see "Docs" below.
- `assets/icon/`: the logo and app icons.

## UI: `apps/desktop/src`

- Entry: `main.tsx` imports every stylesheet, including Frost (`ui/themes/frost.css`), the only look-specific stylesheet as static imports; never load a look stylesheet with a dynamic `import()` (lesson FIX42; `ui/themeBuild.test.ts` enforces it). `blob/bitbots.ts` normalizes retired cached themes to Bitbots. `index.html` has a tiny pre-paint script that sets `data-theme`, `data-style`, `data-glass` and friends from localStorage.
- `ui/App.tsx` (~3,900 lines): the main shell, window settings (`applyWindowSetting`), command palette, routing between pages, companion and dictation modes (`?companion=1`, `?dictation=1`).
- Settings: `ui/SettingsSheet.tsx` (pages list `PAGES`, page bodies), `ui/AppearancePage.tsx` (looks with `LookOrb`, wallpaper, glass, colour, fonts, text size, density), `ui/settingsIndex.ts` (settings search; add an entry for every new setting), `ui/SettingsParts.tsx` (`SettingsGroup`, `SettingsRow`, `HelpTip`), `ui/SegmentedControl.tsx` (radio-group segmented control; use it, do not hand-roll one).
- Haze look: `blob/haze/` (`icons.ts` icon ids and 12×12 pixel art, `HazeMark.tsx` the mark that `BlobCanvas` returns whenever the style is `haze` and no `art` prop forces one, `HazeAura.tsx` the cross-fading status gradient and `auraStatusFor`, `runtimeRegistry.ts` which runtime each `agentLook` result belongs to, filled by `App` from `snapshot.runtimes` in a layout effect, `haze.css`), `ui/themes/haze.css` (tokens, backdrop, compact rows, companion). The companion's expanded layout is the one `shell` in `Companion` (`ui/App.tsx`, class `companion-shell`, parts `cs-roster`, `cs-head`, `cs-body`): roster + header + one pane that shows `chatPane`, `permissionStack`, `activityPane`, `settingsPane`, the drop or dizzy card or a side conversation; every look uses it (see design-language.md). `ui/CompanionResize.tsx` draws the resize handles; a bot with no conversation opens into a local draft here too. The look editor shows an icon picker in Haze (`LookEditor`, `runtimeId` prop).
- Looks: `ui/appearance.ts` (`ThemeStyle`, `THEME_STYLES`, `THEME_LOOKS`, `DEFAULT_THEME_STYLE`, accent helpers), `blob/bitbots.ts` (style store, `useThemeStyle`, sets `data-style` and clears the retired `data-bitbots` marker; nothing sets `data-bitbots` any more, and `ui/accent.css` keeps `:not([data-bitbots="on"])` guards left from Legacy), `ui/theme.css` (base tokens, dark and light), `ui/themes/frost.css` (scoped `:root[data-style="<look>"]`, with separate companion/dictation sections), `ui/accent.css`, `ui/density.css`, `ui/polish.css`, `ui/fonts.ts` (24-font catalogue, `applyFonts`, per-look defaults), `ui/AppWallpaper.tsx` (Frost wallpaper layer), `ui/LookOrb.tsx`, `ui/LookPicker.tsx` (onboarding cards), `ui/LookPreview.tsx`.
- Bots and art: `blob/BlobCanvas.tsx` (the one avatar component; dispatches on art), `blob/art/art.ts` (`BotArt`, `defaultArtForStyle`, `resolveArt`, `resolvePaint`, the 18→8 mood map), `blob/art/{FlatRobot,PopRobot,DotRobot,PaintedBlob}.tsx` + `art.css` (light SVG arts; `PopRobot` is labelled "2D robot"; Flat and Dot are kept for saved bots and the character sheet, not offered in the picker: `ROBOT_ARTS` in `art.ts`), `blob/BitbotCanvas.tsx` + `vendor/robot-heads/` (heavy 3D robot, canvas), `blob/blobEngine.ts` (glossy blob, canvas; also the status-badge model the painted art copies), `blob/look/` (`BlobLook`: `shape`, `seed`, `traits`, `bot`, `art`, `paint`; `normalizeLook`, `agentLook`, `shuffleLook`), `blob/characterState.ts` (the 18 `BlobMood`s), `ui/companionStatus.ts` (mood from session state), `ui/LookEditor.tsx` (bot editor: Style picker, shape grids, colour), `ui/BotEditor.tsx` (3D robot outline and colours), `ui/blobShare.ts` (bot import/export).
- Conversations and team: `ui/TeamSidebar.tsx` (bot rows), `ui/ComposerControls.tsx`, `ui/SafeMarkdown.tsx` + `ui/openSafeLink.ts` (links only through the safe opener), `ui/ApprovalCard.tsx`, `ui/ManagerPage.tsx`, `ui/WorkingBotsPanel.tsx`, `ui/CompanionTeam.tsx`, `ui/CompanionPanels.tsx`.
- Tasks (expansion phase 1, merged to `main` at `26ec193`; the board is also in the browser preview): entry point is the Tasks icon button in the sidebar header (`ui/App.tsx`, state `tasksOpen`; the page replaces the main content while open). `ui/TasksView.tsx` (the page, the new-task and task dialogs), `ui/DelegateBoard.tsx` (Unassigned list on the left, a lane per bot on the right; drag a task onto a bot), `ui/TaskTree.tsx` (node-graph tree), `ui/TaskTimeline.tsx` (labelled timeline), `ui/taskModel.ts` (pure helpers), `ui/useTasks.ts` (`task.*` RPCs and events), `ui/tasks.css` (scoped under `.tasks-page`), `preview/fixtureTasks.ts` (preview-only task ledger that mimics the contract; the board in the browser preview reads it, not the daemon). The `BoardTask` types are in `apps/desktop/src/types.ts`. Tests: `ui/taskModel.test.ts`, `ui/taskViews.test.ts`, `ui/DelegateBoard.mounted.test.tsx`.

- Live review surfaces (2026-10-20): `ui/ArchivedBots.tsx` restores archived bots; `agent.purge` in daemon/storage permanently deletes bots and both sides of related conversations; `ui/SettingsSkeleton.tsx` composes the shared Skeleton. `blob/art/useEyeTracking.ts` handles large painted avatars. `scripts/dev-windows.ps1` now defaults to a private daemon database.
- Task dialog parts (FIX43): `ui/TaskForm.tsx` (every field, images, When, time limit; one form for new and edit), `ui/ScheduleWhen.tsx` (the repeat or once controls and next run times, shared with `SchedulesView`), `ui/schedulePreview.ts` (`automation.preview` reply to labels), `ui/TaskImageStrip.tsx` (read-only thumbnails), `ui/TasksView.tsx` (`TaskFormDialog`, `TaskDetailDialog`). Scheduled tasks list apart from drafts (`isScheduled`, `scheduledTasks` in `taskModel.ts`).
- Bridges: `tauri.ts` (every native and daemon call the UI makes), `desktopIntegrations.ts`, `transport/nativeBridge.ts`, `transport/platform.ts`.
- Remote PWA: `remote/` (`RemoteApp.tsx`, `remoteTauri.ts` must export every name `tauri.ts` exports, as refusing stubs for native-only functions; `remoteTiers.ts` + `tiers.json` policy).
- Preview harness: `preview/` (`fixtureBridge.ts` replaces `tauri.ts` in the browser preview and must mirror its exports; `main.tsx` = character sheet `/preview.html`; `gallery.tsx`, `launchPreview.tsx`, `dictationPreview.tsx`, `polishPreview.tsx`). Design studies, not in the production build: `/redesign-preview.html` (`preview/redesignPreview.tsx`) and the Mini skin study at `/preview1`, `/preview2`, `/preview3` (`apps/desktop/preview{1,2,3}.html` → `preview/mini/`; `body[data-variant]` picks Haze, Vision or Aurora; `miniCore.tsx` holds the `Aura` status gradient and the mask-tinted runtime `Logo`, `miniTasks.tsx` the board, timeline and tree, `miniData.ts` fixtures and a five-field cron `nextRuns`). Vite serves `/previewN` from `previewN.html` without the extension.
- Release notes in the app: `ui/WhatsNew.tsx` imports `docs/releases/*.md`.

## Daemon and crates

- `crates/bloblex-daemon/src/`: `main.rs` (`dispatch()`, settings validation `validate_setting`, tests), `team.rs` (Manager tools and schemas), `proposals.rs`, `queue.rs`, `retry.rs` (watchdog/continuation), `automations.rs`, `tasks.rs` (durable board tasks: `task.*` RPCs, owner dispatch/queue, turn-end mapping, task images in `<data>/task-images/`, the schedule sweep, the time limit; `is_unattended` in `main.rs` keeps scheduled task runs under the automation rails), `memory.rs`, `skills.rs`, `backup.rs` (`SETTING_ALLOWLIST`, a fixed-size array), `diagnostics.rs`, `worktree.rs`, `quota*.rs`, `catalog.rs`, `remote/` (gateway, Tailscale, Native, pairing).
- `crates/bloblex-storage/src/lib.rs`: SQLite schema and migrations, `validate_setting_value`, `validate_agent_fields`, `valid_look`; the task ledger (`ensure_tasks_schema`, `task_*` reads and writes) with append-only `task_run_events`.
- Others: `bloblex-adapter-{claude,codex,acp,opencode}`, `bloblex-agent-core`, `bloblex-runtime`, `bloblex-process`, `bloblex-protocol`, `bloblex-usage`, `bloblex-budget` (retired; `budget.*` returns unsupported), `bloblex-security`, `bloblex-speech` (on-device and opt-in cloud dictation: `catalog.rs` pins every model, `engine.rs` wraps sherpa-onnx and the Whistle runner, `utterance.rs` cuts audio into utterances for live partials from offline models, `needle.rs` runs Cactus's `needle.exe`), `bloblex-wsl`.
