# Bloblex Product

## Register

product

## Users

Developers on Windows who already use Claude Code, Codex, or OpenCode. They need to move among agent conversations without losing track of sessions, approvals, runtime health, project context, or usage.

## Product Purpose

Bloblex is a local desktop control plane for authenticated coding-agent CLIs. It presents one conversation interface backed by a separate local daemon. Provider authentication stays with each CLI. The product succeeds when users can discover a real runtime, start or resume a session, follow its normalized events, and recover accurately after reconnects.

## Brand Personality

Calm, capable, characterful. The voice is concise and honest about unknown or unsupported states. Original circular blob characters make runtime state legible without turning the interface into a toy.

## Anti-references

- Three embedded terminal windows as the primary interface.
- Dashboard overload, permanent charts, and nested navigation trees.
- Fabricated agent conversations, authentication, pricing, or successful actions.
- Provider logos or copied reference assets.
- A top-edge notch companion. The Bloblex companion is a draggable rounded rectangular bill, bottom-center by default, with island behavior and corner geometry.
- A generic status pill or mouth-based character expressions. Preserve the welcome wave, stateful home/chat views, and mouth-free expressions requested in the reference feedback.

## Design Principles

1. Make real daemon state the source of truth across every surface.
2. Keep the three-column conversation UI sparse and task-centered.
3. Make uncertainty explicit: unknown means unknown, never success or free.
4. Use original blob characters as state indicators with motion that communicates activity.
5. Keep local control and user intent clear for permissions, process lifecycle, and file actions.

## Accessibility & Inclusion

Support keyboard navigation, visible focus, accessible labels, and high-contrast state text alongside color. Respect reduced-motion preferences and pause animation when hidden. Companion controls must remain keyboard-accessible through the main app and tray.
