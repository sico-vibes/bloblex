# Bitbots 0.1.0-beta.48

This release is about speed. If you run beta.32 or later, this version downloads by itself.

## Added

- **Projects in the composer.** Type `#` and a project's name or one of its tags to name it. Naming a bot with `@` then offers the projects. Carry on typing and the added `#` goes away. A new conversation opens in the project its message names.
- **The Manager asks which project.** When a request needs a project and none was named, the Manager asks which one. A project tag that fits several projects is refused, and the reply lists their names.

## Changed

- Settings no longer waits behind the app's background loading, so it should open without the long loading placeholder.
- Project and bot icons change the moment you pick them. If a save fails, the old icon comes back and the reason is shown.
- Saving a bot's icon or name no longer checks the provider's model list first.
- Sending a message and creating a project no longer reload everything afterwards.
- The New project dialog is ready at once; the GitHub sign-in check finishes in the background.
- The app starts faster. It reuses its copy of the background service, and your history loads faster. The folder pickers no longer freeze the window.
- The first load after starting the app can still take a few seconds on a large history.

## Fixed

- The approval card now shows the project when the Manager names it by a tag.

## Installation

Running beta.32 or later: wait for **Restart to update**, or check now in Settings › Updates. Older versions: download `Bitbots_0.1.0-beta.48_x64-setup.exe` and verify it against `SHA256SUMS.txt`.
