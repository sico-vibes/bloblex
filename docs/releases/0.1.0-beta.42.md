# Bitbots 0.1.0-beta.42

This release fixes OpenCode bots, lets a connected Claude Code session edit your bots, and starts the move to bots that work across projects. If you run beta.32 or later, this version downloads by itself and shows **Restart to update** in the top bar.

## Fixed

- **OpenCode bots keep their effort.** A bot with instructions could fail its first turn with "OpenCode rejected the effort setting". OpenCode reset the effort while it switched to the bot's instructions. Bitbots now sends the model and the effort together, checks that OpenCode kept them, and tries again if it didn't.
- **No more failed question cards from OpenCode.** OpenCode's own question tool can't reach you through Bitbots, so it showed up as a failed step. It's now turned off for OpenCode bots, and they ask in their reply instead.
- **The Bitbots MCP says why a turn failed.** `wait_for_turn`, `turn_metrics` and `read_conversation` now include the error and its detail.

## Added

- **A connected session can edit bots.** At the **Operator** level, the Bitbots MCP can change a bot's:
  - name, role, description, instructions and colour;
  - coding agent, model, effort and speed;
  - approval mode, default project folder and tags;
  - whether it's hidden, and its notifications.

  It can't change a bot's custom arguments or environment. It can't lock, unlock, archive or delete a bot, and it can't change a locked bot at all.
- **Full access stays your choice.** A connected session can give a bot **Full access** only after you turn on **Let them give bots Full access** in **Settings › Connections** and confirm. Turning the MCP off turns this off too.
- **Conversations grouped by project.** A bot's conversations are now listed under the project each one works in. Each project heading has a **+** for a new conversation there, and a menu to rename the project, change its folder, edit its tags or delete it. **New conversation** has a project picker.

## Changed

- **One list of bots.** The sidebar and the companion list your bots in one list, with the Manager on top, instead of grouping them by project. A bot's menu now sets its **Default project**: where its new conversations start.
- **Project tags** moved from the sidebar headings to the project menu in the conversations panel.

## Coming next

Bots across projects isn't finished. A later beta adds the background service's half:
- starting a conversation in any project you pick, including **No project**;
- **Always in this project** next to **Always, every project** on approval cards;
- changing where a saved approval applies, in Settings › Approvals.

Until then, approvals keep working as before.

## Installation

Running beta.32 or later: wait for **Restart to update**, or check now in Settings › Updates. Older versions: download `Bitbots_0.1.0-beta.42_x64-setup.exe` and verify it against `SHA256SUMS.txt`. The installer is not Authenticode-signed (Windows may warn).
