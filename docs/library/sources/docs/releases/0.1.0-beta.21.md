# Bloblex 0.1.0-beta.21

A performance release for Bitbots, plus one dictation change. **Verified with unit tests and browser fixtures, not in the installed app against live provider turns.**

## Changed

- **Bitbots is much lighter.** Robots that are idle or asleep now hold their still pose instead of redrawing every frame, robots scrolled out of view or in a hidden window do not draw, small avatars update at about 15 fps, and the shared animation loop is capped near 30 fps. In the browser preview with eight robots on screen the frame rate went from about 10 fps to about 100 fps. Busy, asking, hovered and large robots still animate. The robot library (`robot-heads`, MIT) is now vendored in the app with these changes and its licence.
- **On-device speech model first.** Dictation now always makes sure the on-device model is downloaded before it starts, whatever engine is chosen, so there is always something to fall back on.
- **ChatGPT dictation retries the way bb does.** If OpenAI's edge answers with a bot challenge, Bloblex keeps the Cloudflare cookies from that response in memory and retries once carrying them. **It is still challenged from the machine it was tested on**, so ChatGPT dictation remains unavailable there. Use "On this device".

## Compatibility and data

No data or settings changes.

## Verification

- Rust workspace excluding the desktop crate: 472 tests passed before the speech-crate additions; the speech crate now has 54 (three new for the cookie retry). Desktop UI: typecheck clean, 520 tests passed, production build.

Unverified: the performance gain in the installed app's native windows, and ChatGPT dictation on any machine other than the one tested.

## Manual installation

Download `Bloblex_0.1.0-beta.21_x64-setup.exe` and verify it against `SHA256SUMS.txt`. The installer is unsigned (Windows may warn). No updater manifest is published; the signed `channel-beta` feed remains at beta.6. Install beta.21 manually over your current version.
