## Original plan and accepted choices

The expansion adds a durable task workspace beside the existing bots, conversation rail and chat. It connects task cards, Manager delegation, run history, schedules and supervision without replacing existing approval cards as the default delegation path. Tree and timeline are alternate views of real task and attempt records, not a fabricated bot hierarchy or inferred timing chart.

The desktop plan also adds a persistent native PTY dock, local chat-surface image effects, Cursor and Grok Build onboarding, free OpenCode setup guarded by a real tool round-trip, a read-only GitHub inbox, scoped connector access, and optional local computer grants. Remote adds a local-development relay method while preserving the existing remote tier policy. Phone task screens are read-only; phone chat remains subject to operator tier and local computer grants. There is no hosted relay deployment in this plan.

Accepted product constraints include bounded runtime and correction caps, explicit future schedule authorization, unknown values kept unknown, no invented rates or completion from elapsed time, no provider secret exposure, no silent paid fallback, exact per-tool connector grants, and screenshots sent only into the selected provider call path. The full accepted scope and ownership are listed in the plan and consolidated handoff linked above.
