# Bloblex 0.1.0-beta.25

An OpenCode 2 follow-up. **Verified with unit tests, the standard gates and a
live run of the model catalog against OpenCode 2.0.28 on the machine it was built
on. A real OpenCode conversation end to end was not run.**

## Fixed

- **Every OpenCode model shows its own effort levels.** On beta.24 only the model
  OpenCode started its session on had effort levels; every other model, such as
  DeepSeek V4.1 Flash, said "This model does not report selectable effort
  levels". OpenCode 2 reports one effort list at a time, for the model currently
  selected in a session, and rebuilds it when the model changes. Bloblex now
  selects each model once in a throwaway session, reads that model's levels back
  (about 10 ms per model, no model call), and shows them. DeepSeek V4.1 Flash
  offers Low, High and Max; Kimi K3 offers Max; models with no effort control
  show none.
- **The model list is no longer marked "Suggested models, not checked with
  OpenCode".** The list is OpenCode's own complete list and each model's levels
  are OpenCode's own answer, so the catalog counts as checked when every model
  answered. If any model could not be read, it stays marked as unchecked and
  keeps what was learned.

## Changed

- The catalog read is bounded: two seconds per model and the existing overall
  catalog timeout, and the probe session is always closed.

## Verification

- Rust workspace excluding the desktop crate: 497 tests pass (the OpenCode
  adapter gains tests for the per-model walk, the all-answered case, a budget
  cut that keeps partial results and leaves no child process, and that a model is
  selected before its effort). The daemon binary tests need
  `RUST_MIN_STACK=33554432` on this machine (pre-existing).
- Live against OpenCode 2.0.28: `source=config_options`, validated, 114 models,
  92 with effort levels, `deepseek-v4.1-flash` low/high/max, 3.6 s including the
  failed `models --verbose` attempt.
- No desktop changes since beta.24.

Unverified: a real conversation at a chosen effort, other OpenCode 2 releases, a
model list that changes while Bloblex is running (the catalog is cached for 60
seconds), and clean-machine installation.

## Manual installation

Download `Bloblex_0.1.0-beta.25_x64-setup.exe` and verify it against
`SHA256SUMS.txt`. The installer is unsigned (Windows may warn). No updater
manifest is published; the signed `channel-beta` feed remains at beta.6. Install
beta.25 manually over your current version.
