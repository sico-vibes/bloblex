# Bloblex 0.1.0-beta.6

## Changes

- Improve OpenCode Zen and Go sign-in detection, gateway naming, and credential-output filtering.
- Make budget reservation cleanup transactional when sessions or policies are archived, deleted, or retargeted.
- Persist discovered runtimes on refresh without creating unexpected blobs.
- Refine provider setup, usage and limits, and wardrobe previews.
- Show complete outfit silhouettes across all sizes, colours, and directions.

## Known limits

- This build is not Authenticode code-signed. It has no live-provider session validation or native-window acceptance pass.
- Cost budgets are not offered yet.
- The wardrobe and launch checks were verified through fixtures and automated tests, not a clean-machine native install.
