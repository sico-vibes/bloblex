# Bitbots 0.1.0-beta.41

This release adds the Bitbots MCP: a Claude Code session you start in a terminal or editor can now see and work with your bots. If you run beta.32 or later, this version downloads by itself and shows **Restart to update** in the top bar.

## Added

- **The Bitbots MCP.** It is off until you turn it on in **Settings › Connections**. You then pick what outside sessions may do:
  - **View:** see your bots, projects, conversations and how long turns take.
  - **Chat:** also message, steer and stop bots, and start conversations.
  - **Operator:** also create bots, answer approvals and start work in a new git worktree, so it can't clash with your own working folder.

  To connect Claude Code, copy the command on that page and run it once in a terminal.
- **What a connected session never gets.** It uses its own key, never your coding agents' sign-ins or Bitbots' own key, and it can't reach Bitbots from another device. A bot it creates starts on **Ask**, never **Full access**.
- **Turning it off.** Turning the MCP off cuts every connected session off at once. **Reset access** makes a new key.
- **Messages show who sent them.** A message sent through the MCP shows **via Claude Code** in the conversation and in the companion, so it never reads as one you typed.

## Changed

- **More room for Bitbots' background service.** Its worker threads now get a larger stack, after a development build ran out during shutdown.

## Installation

Running beta.32 or later: wait for **Restart to update**, or check now in Settings › Updates. Older versions: download `Bitbots_0.1.0-beta.41_x64-setup.exe` and verify it against `SHA256SUMS.txt`. The installer is not Authenticode-signed (Windows may warn).
