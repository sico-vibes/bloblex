# Bitbots 0.1.0-beta.36

A fix-only release. The looks introduced in beta.35 did not apply in the installed app, and this version makes Bitbots (Frost), Pop and Dot load their own styles. If you run beta.32, beta.33, beta.34 or beta.35, this version downloads by itself and shows **Restart to update** in the top bar.

## Changed

- **Documentation.** A new documentation library (`docs/DOCUMENTATION.html`) with user guides and reference pages, and a tidier repository root.

## Fixed

- **Looks did not apply in the installed app.** In beta.35, Settings showed Bitbots (Frost) and a wallpaper selected, but the window stayed plain dark, and Pop did not apply either. The browser preview looked right. The production build loaded only Dot's stylesheet, whichever look was chosen. Every look's styles are now part of the app's main stylesheet, so Bitbots (Frost), Pop and Dot each load their own. A new test stops look styles being loaded on demand again. Legacy still loads its pixel fonts on demand.

## Verification

- Desktop UI (Vitest): 1,354 tests in 181 files passed. `npx tsc -b` is clean.
- Production web build succeeded. Its main stylesheet contains the rules for the Bitbots, Pop and Dot looks.
- Rust workspace tests, excluding the desktop crate: `bloblex-daemon` 456 and `bloblex-storage` 119 passed. Clippy is clean.
- Desktop library tests passed from a short-path build.

Unverified: the fix has not yet been checked in an installed beta.36 build; it was checked only in the production bundle. Not yet checked: the transparent companion and dictation windows over other apps; the wallpaper picker through the native file dialog; the Geist font in the native window (the face did not load in the preview); a dictation window follows a theme change only the next time it opens; the remote (phone) web app still shows robots by default; the new bot styles in live provider sessions, and the Manager with a live model; the main-window looks, which were checked only in the preview and the tests; and the update to this version and a clean install on a real machine.

## Installation

Running beta.32, beta.33, beta.34 or beta.35: wait for **Restart to update**, or check now in Settings › Updates. Older versions: download `Bitbots_0.1.0-beta.36_x64-setup.exe` and verify it against `SHA256SUMS.txt`. The installer is not Authenticode-signed (Windows may warn).
