# Bloblex 0.1.0-beta.22

A dictation release. **The cloud engine is verified live on the machine it was
built on; everything else is verified with unit tests and the standard gates,
not against live provider turns in the installed app.**

## Changed

- **ChatGPT dictation now gets through OpenAI's edge.** The cloud engine was
  answered with a Cloudflare bot challenge (`403`, `cf-mitigated: challenge`)
  because the client used this platform's default TLS stack — `native-tls`, i.e.
  SChannel on Windows — whose TLS ClientHello fingerprint is challenged. The
  cloud client now uses `rustls`, whose fingerprint is accepted. The request is
  otherwise identical: same endpoint, same multipart body, same
  `model=gpt-transcribe`, same `originator: bloblex`, our own User-Agent. No
  other application's identity is used, and nothing is spoofed.
  Verified live on the tested machine with the shipped client: `challenged`
  before, `ok` after, reproduced twice.
- **Nothing else about dictation changed.** On-device stays the default engine
  and the automatic fallback. Cloud dictation stays opt-in with explicit
  consent, reads the Codex sign-in read-only, and still never persists or logs
  the token, the audio or the transcript. The bot-challenge mapping, the
  ten-minute cool-down and the honest message all remain, because the accepted
  shape can change without warning.
- **Where the permission comes from.** The endpoint is a private ChatGPT route.
  Its use here rests on the owner's account of OpenAI's reply naming it, which
  is recorded in `AGENTS.md` as **owner-attested** — no copy of that
  correspondence is in this repository and no agent has verified it. If the
  endpoint or its terms change, that exception lapses.

## Verification

- `bloblex-speech`: 56 tests (2 new: the cloud client's TLS configuration and
  its construction).
- Rust workspace excluding the desktop crate: passes. The `bloblex-daemon`
  binary tests need a larger test-thread stack on this machine
  (`RUST_MIN_STACK=33554432`); without it one async test overflows its stack in
  the debug build. That is pre-existing and unrelated to this change.
- Live before/after with the shipped client, 1.2 s of silence: `error
  code=challenged` → `ok`.
- Evidence: `docs/evidence/cloud-dictation-tls-backend-2026-10-14.md`,
  `docs/evidence/cloud-dictation-client-shape-2026-10-14.md`.

Unverified: real speech through a live microphone, any machine or network other
than the tested one, whether the accepted shape holds over time, and the
endpoint's permission status independent of the owner's account. A `200` is not
authorization.

## Manual installation

Download `Bloblex_0.1.0-beta.22_x64-setup.exe` and verify it against
`SHA256SUMS.txt`. The installer is unsigned (Windows may warn). No updater
manifest is published; the signed `channel-beta` feed remains at beta.6. Install
beta.22 manually over your current version.
