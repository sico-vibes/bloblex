# Bitbots 0.1.0-beta.40

A polish release after beta.39, from your own review of the app. If you run beta.32 or later, this version downloads by itself and shows **Restart to update** in the top bar.

## Changed

- **Assignments read like messages.** When the Manager hands out work, the conversation shows a centred **Messaged** line with the teammates' faces, names, a count and the time, like **Message from**. Click it to open the assignments in place. Each one shows its status on the same line as **Open**, and hovering highlights the text instead of drawing boxes.
- **Haze is glass all the way.** Settings, dialogs, the bot save bar and the terminal are frosted glass over the haze instead of flat grey panels.
- **Composer.** The coding agent's logo on the model button is larger, the thinking level has a brain icon, and **Steer** and **Queue** sit beside the send button while a bot is working.
- **Conversations panel.** One **New conversation** button sits under the title, and the button that hides or shows the panel sits next to the bot's name.
- **Changes.** The list shows the first eight files, with **Show all** for the rest. The Manager, which works in its own folder, explains that it has no code changes instead of showing a Git error.
- **Tables.** An opened row lines its labels up in one column, with the full values beside them.

## Fixed

- **White dots appeared next to conversations after switching between them quickly.** A conversation now counts as unread only when it has something new to read.
- **The Health check said the hook bridge was missing in an installed app, without saying how to fix it.** It looked in the wrong folder; it now finds the bridge, and when the bridge really is missing it says to reinstall the latest release. **Watch Claude Code outside Bitbots** had the same problem and now works in an installed app.

## Installation

Running beta.32 or later: wait for **Restart to update**, or check now in Settings › Updates. Older versions: download `Bitbots_0.1.0-beta.40_x64-setup.exe` and verify it against `SHA256SUMS.txt`. The installer is not Authenticode-signed (Windows may warn).
