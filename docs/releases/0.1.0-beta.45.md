# Bitbots 0.1.0-beta.45

This release adds accounts, secrets, webhooks, phone notifications and more coding agents. If you run beta.32 or later, this version downloads by itself.

## Added

- **Accounts.** Settings › Accounts shows who each coding agent is signed in as, read from the agent's own command and never from a token. Add more accounts for a provider, and choose one in a bot's settings.
- **Custom models.** Add a model id a catalog doesn't list, with its effort levels.
- **Gemini CLI and Qwen Code** run as coding agents when they're installed. Both vendors mark this mode as experimental.
- **Secrets.** Settings › Secrets keeps environment values in the Windows Credential Manager, and a bot gets one by name. This protects the value on disk. A coding agent can still read its own environment.
- **One-use secrets.** A bot can ask you for a secret for one turn, in a secure form. You have under a minute to answer, for now.
- **Phone notifications.** Off until you turn them on in Settings › Remote. A notice says only "Rae needs you" or "Rae's turn failed", and it goes through your phone maker's push service.
- **Webhooks.** A schedule can start from a signed request while Remote is on. Open a schedule's history to turn it on. The secret is shown once, and a request without a valid signature looks like a missing page.
- **Visual replies.** HTML and SVG from a bot can be previewed in a frame where nothing runs.
- **Terminal.** Links open when you click them, and a tab shows the commands the bot ran, read-only.
- **Sidebar.** Sort bots by recent, name or status, and group them by project. Finished conversations settle below live ones.

## Changed

- **Codex's protocol is pinned.** The health check warns when your Codex is newer than the version Bitbots was checked against.
- **CI.** Every push now runs the tests and a performance check on GitHub.

## Not yet checked on real hardware

Tested with real daemons on one computer: accounts, custom models, the real Credential Manager, and real signed webhooks through a real gateway. **Not tried for real:** a second sign-in with a real provider, Gemini or Qwen themselves, a notification on a real phone through a real push service, and a webhook from another computer.

## Installation

Running beta.32 or later: wait for **Restart to update**, or check now in Settings › Updates. Older versions: download `Bitbots_0.1.0-beta.45_x64-setup.exe` and verify it against `SHA256SUMS.txt`.
