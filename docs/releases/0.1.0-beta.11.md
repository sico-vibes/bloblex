# Bloblex 0.1.0-beta.11

## Changes

- Add on-device dictation to the composer and the companion. Press Ctrl+E, or the mic button, to talk and insert the transcript into the draft. Speech runs locally with sherpa-onnx; audio never leaves the device.
- Add a new `bloblex-speech` Rust crate: pinned model catalog, 16 kHz mono resampling, bounded offline chunking, and an owner-locked session lifecycle shared by the desktop and companion surfaces.
- Download the selected model from Hugging Face on first use with per-file SHA-256 verification and resume. Add a Settings → Speech model manager with live download progress.
- Show a live provisional transcript while listening, reuse a warm decode worker across sessions (released after two idle minutes), and wire the Ctrl+E global shortcut.

## Verification

- All 361 desktop tests, typecheck, and the production web build passed for the feature commit.
- The full offline Rust workspace suite passed, including 19 `bloblex-speech` unit tests; the desktop crate type-checks with the `native` feature enabled.
- Live microphone capture, real model inference, and clean-machine installation remain unverified for this update.
