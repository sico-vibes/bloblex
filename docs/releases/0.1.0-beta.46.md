# Bitbots 0.1.0-beta.46

This release adds sub-bots: ask a bot for a fleet, and watch every one of them work. If you run beta.32 or later, this version downloads by itself.

## Added

- **Sub-bots.** Tell a bot "spawn 3 sub-agents on Haiku to research X". It can start up to 5 at once, each on its own model, including a different coding agent from its own. Each result comes back to the bot that asked.
- **See every sub-bot.** They sit under their bot in the sidebar with what each is doing. The conversation that started them shows the fleet, with model, state, Open and Stop, and Stop all. The companion shows a count, such as "2/3 working".
- **Each sub-bot is a real conversation.** You can open it, read everything and message it directly.
- **Claude's own sub-agents stay visible.** When Claude Code starts its own background agent, the conversation now shows "Started 1 sub-agent", with its steps nested under it, even with Agent activity off.

## Limits

- A sub-bot can't start its own sub-bots, and it never has more access than the conversation that started it.
- Sub-bots can't be started from unattended work, such as a schedule or a board task.
- Deleting a bot archives its sub-bots and stops any still working.
- The phone sees each sub-bot's name, model and state, but not what it's doing or its errors.

## Fixed

- A cleanup scan could call a live task copy abandoned when Windows spelled the folder with a short name.

## Not yet checked on real hardware

Tested with a real daemon: a Go bot started real sub-bots on Claude Haiku and on the Go model, both answered, one took a direct message, and deleting the parent archived them. Claude's own sub-agents are tested from a recorded real transcript. **Not tried for real:** the new screens inside the installed app (they were checked in the browser preview), and a phone view of the fleet, which doesn't exist yet.
