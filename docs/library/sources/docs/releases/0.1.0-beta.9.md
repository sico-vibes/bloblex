# Bloblex 0.1.0-beta.9

## Changes

- Resume saved conversations before sending a prompt after Bloblex has reopened.
- Keep each conversation on its selected model and effort; changing the model asks for confirmation and starts a fresh provider context while retaining Bloblex messages.
- Show provider-reported conversation titles from Codex and OpenCode when available. Claude print-mode title metadata is not surfaced because a reliable structured source could not be verified.
- Show provider-reported context usage in the composer, with a percentage only when both used tokens and window size are known.
- Add a keyboard-accessible message outline and hold-to-confirm for conversation deletion.
- Retain beta.8's Codex, Claude Code, and OpenCode Go quota meters and token usage reporting.

## Verification

- Desktop tests, typecheck, and production web build passed.
- Full offline `cargo test --workspace` passed from a short-path checkout after staging the desktop sidecar resources. The default apostrophe-containing checkout path is not accepted by Windows `rc.exe`.
- Native UI and live provider verification for these changes remain open.

## Manual installation

Download `Bloblex_0.1.0-beta.9_x64-setup.exe` (7,366,759 bytes; SHA-256 `ad1525a8ecce9d1aba9a89da42bb662053c6582a68c9da562a5104d52a700746`) and verify it with the attached `SHA256SUMS.txt`. It has no Authenticode signature, Tauri updater signature, or updater manifest. The rolling `channel-beta` feed remains at beta.6. Windows may show a SmartScreen warning on first install.
