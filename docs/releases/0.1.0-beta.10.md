# Bloblex 0.1.0-beta.10

## Changes

- Add separate model and effort controls to the composer, using each model's advertised effort levels.
- Port the reference Claude pixel/spring meter and Codex gradient/particle meter into Bloblex's UI, with reduced-motion and keyboard support.
- Keep conversations on their saved model and effort. Changing the model requires confirmation; starting and resuming sessions now preserve the correct blob options and reject stale model-lock races.
- Show a compact context-window ring with reported token usage and capacity. Fresh provider contexts clear old context usage; missing values remain unknown.
- Add paired prompt/reply previews and reference-derived motion to the conversation outline.
- Add hold-and-release deletion with an awaited success transition and retryable errors for conversations and custom launcher profiles.
- Retain beta.9's conversation resume, provider title updates, token analytics, and quota meters.

## Verification

- All 361 desktop tests, typecheck, and production web build passed for the feature commit.
- The offline backend workspace suite passed with installed-provider smoke explicitly disabled.
- Browser fixtures verified light/dark meters, reduced motion, keyboard effort selection, model confirmation, the minimum native window width with the details pane, and hold/release deletion.
- Native UI, real-provider turns, and clean-machine installation remain unverified for this update.

## Manual installation

This beta follows the recent unsigned manual-install prereleases. The release provides `Bloblex_0.1.0-beta.10_x64-setup.exe` and `SHA256SUMS.txt`. It has no Windows Authenticode signature, Tauri updater signature, or updater manifest. The signed rolling `channel-beta` feed remains at beta.6. Windows may show a SmartScreen warning on first install.

Reference commit provenance and MIT notices are included in `THIRD_PARTY_NOTICES.md`.
