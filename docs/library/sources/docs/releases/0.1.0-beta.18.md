# Bloblex 0.1.0-beta.18

## Changes

- **Claude effort recovery:** an incompatible saved effort now has a repair action in main and companion that keeps the selected model. This configuration error is separate from a provider usage limit and does not mark the entire CLI unhealthy.
- **Explicit models:** remove Provider default and Default (recommended) model entries. A new bot initially selects the latest available Sonnet for Claude, latest Luna for Codex, or Big Pickle for OpenCode. Existing explicit selections remain pinned. Missing target models require an available concrete choice.
- **Model order:** Claude models appear chronologically across families. OpenCode uses reported release dates within its provider groups. Codex generations remain newest first.
- **Claude Ultracode:** add Settings → General → Experimental → Claude dynamic workflows, off by default. Enabled new conversations receive session-local workflow settings, preserved through later model/effort/speed changes. Eligible models expose Ultracode separately from Max; Ultracode uses Extra high plus its dedicated workflow flag. Claude's own configuration and managed policy remain authoritative. Codex Ultra remains available only on models whose catalog reports it; Luna stops at Max.
- **Context window:** query Claude's native structured context report before the first prompt and after completion or compaction, with bounded requests and protection against stale responses. Its estimate is labelled Estimated context. OpenCode uses reported context usage and available catalog capacity. Unknown readings stay unknown; model changes clear old attribution, and child-session usage cannot overwrite parent context. Main and companion share persisted normalized state.
- **Controls:** runtime-logo tooltips open below the icon and stay within the viewport, including keyboard focus. The effort control uses the same opening/closing chevron behavior as the model control. Usage Back and Refresh are borderless icon buttons with accessible labels.
- **Usage visuals:** show each blob's actual portrait, separate the Blobs and provider sections, and add three simple animated weekly liquid orbs for Claude, Codex and OpenCode. Zero is empty, 100% is full, missing data is unknown, and retained stale readings are labelled. Reduced motion and offscreen animation pausing are supported. Provider limits remain account-wide rather than filtered by project or blob.
