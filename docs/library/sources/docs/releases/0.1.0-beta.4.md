# Bloblex 0.1.0-beta.4

## Changes

- Conversations can be renamed, archived, deleted, and marked unread. Windows notifications report activity, tool activity is grouped in the chat, and Bloblex can start with Windows.
- Model lists show their source and update time, distinguish suggestions from validated models, and show display names, defaults, and model families.
- Usage settings include token, turn, and time budgets, price overrides, and subscription fees. Conversations can be exported as Markdown, and blob setups can be exported or imported.
- Press Ctrl+K to switch quickly between blobs, projects, and conversations. Change the model or thinking mode from the composer. Chat supports safe Markdown, unified diffs, and quicker approval shortcuts shared with the companion.
- Codex and OpenCode sessions can share a provider process. Sessions stay separate, recover after a process interruption, and can be cancelled independently.
- New installs get a first-run setup. Companion position and its hotkey can be changed. Choose system, dark, or light theme and adjust text size. Favourites and pins can be reordered.

## Known limits

- This build is not code-signed. It has not had native-window or live-provider verification.
- Cost budgets are not offered yet.
- Codex instructions stay at the thread level.
- Clicking a Windows notification does not focus the app.
