# Bloblex 0.1.0-beta.1

First beta.

## Features

- Companion window
- Blobs and agents
- Sessions tree
- Per-blob model, effort, and speed where the runtime supports them
- Approval modes: ask, auto, and bypass
- Analytics
- Auto-update

## Known limits

- Unit tests use fake processes. This build is not yet verified against live provider CLIs.
- Not yet verified on a clean machine.
- The installer is not code-signed, so Windows may show a SmartScreen warning.
- Windows only.
- WSL launch is not usable yet.
