# Bloblex 0.1.0-beta.15

## Changes

### Effort
- The effort levels match what each coding agent reports.
  - Codex models list Low to Max, and Sol, Astra and Terra models add **Ultra**: maximum reasoning that may hand parts of the task to extra agents.
  - Claude adds **Ultracode** after Max when Claude Code reports it is available (dynamic workflows on, and a model that supports Extra high). Bloblex runs it at Max effort.
- The slider follows your pointer exactly while you hold it, and saves only when you let go. A native slider that fought the drag, and made the knob flash back to the start, is gone.
- "Provider default" sits at the top right on one line. The recommended level is a short line on the track; Claude's style captions it "Recommended" and lights only the cells nearest the knob.
- When a runtime cannot change effort (OpenCode today), the effort pill is greyed out and explains why on hover, instead of showing an error.

### Side conversations
- A teammate's private reasoning (OpenCode stores it as a message) no longer appears in conversations. In a side conversation it used to look like a second message from the blob that asked.
- "Close chat" returns to the conversation you opened the side conversation from, instead of switching to the teammate.
- Each side conversation has a short title given by the blob that starts it. The header shows both blobs and the title in a centred pill, and the blob header lists its side conversations with both avatars, who asked whom and when.
- Blobs can list their side conversations and continue a relevant one instead of starting a new one each time.
- Type `#` in the composer to reference a side conversation. The blob receives its id and latest reply; your message shows it as a chip that opens it.

### Dictation
- Fixed the first click: a freshly started model never began listening, so it took three clicks to dictate.
- The microphone opens at once and audio is kept while the speech model loads, so the first words are not lost. The model is also loaded in the background when Bloblex starts.
- Settings → Speech has a Dictation switch and a choice of which downloaded model to use. Ctrl+E is only taken while dictation is on, and goes to the companion while it is on screen, otherwise to the main window.
- New dictation bubble, adapted from Kaze: a dark island with a recording dot and timer, level bars, and the words appearing as you speak. The companion uses the same design.

### Other
- Removed the header's Resume button; sending a message already reconnects the coding agent. "New conversation" is disabled when the conversation is already empty.
- Every menu item has an icon.
- New experimental setting, **Runtime logos** (Settings → General → Experimental): the coding agent's logo before each blob's name, with its name on hover.
- The browser preview gallery has Onboarding and Dictation sections.

## Verification

- The Rust workspace tests pass, including new tests for Ultracode, titled side conversations, `list_conversations`, continuing a conversation and `#` references.
- Desktop: typecheck, all 373 tests and the production web build pass. The desktop crate compiled with the new native dictation code.
- Checked in the browser preview: the Claude, Codex and locked OpenCode effort selectors, the side conversation menu, pill and Close chat, `#` references, runtime logos, Speech settings and the dictation island.
- Not verified: native dictation (warm-up, queued audio, the bubble growing, Ctrl+E routing), Ultracode on a real Claude turn, and clean-machine installation.

## Manual installation

- Download `Bloblex_0.1.0-beta.15_x64-setup.exe` (12,943,042 bytes; SHA-256 `ea042d9495a7c702f9507a0657ddc52e114558ac6f65adc78cdb8f70aa2e584f`) and verify it against the attached `SHA256SUMS.txt`.
- It has no Windows Authenticode signature (`NotSigned`), Tauri updater signature, or updater manifest. The signed rolling `channel-beta` feed remains at beta.6.
- Windows may show a SmartScreen warning on first install. Install over the existing version to update; your blobs and conversations are kept.
