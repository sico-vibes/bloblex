# Bloblex 0.1.0-beta.20

Built on beta.19 from the owner's review of it. **Everything below was verified with fake providers, unit tests and browser fixtures, not in the installed app against live Claude Code, Codex or OpenCode turns.** Bitbots is experimental and off by default.

## New

- **Bitbots (Settings → Experimental, off by default):** blobs become pixel LED robots (the MIT-licensed `robot-heads` library) and the app takes a pixel look: Doto and DM Mono fonts, square corners, dotted borders, hard shadows, a pixel companion and a welcome where the robot hops with one sudden spin. Robots show what they are doing on their own face, so the corner status badges are gone in this mode. Each blob picks one of four outlines (rectangle, square, circle, hexagon) and its shell, trim and screen colours. The antenna is always off and the speed is always 1.
- **Automations (was Schedules):** an automation is an action a blob performs on a schedule, for example "check my email every morning". The page starts from ideas (morning brief, email check, project check-in, nightly tests). The "send later" clock is gone from the composer.
- **The team leader can create blobs:** ask the leader for a bot or a whole team. Only the leader can; other blobs tell you to tag the leader. Created blobs never run in bypass mode; at most 5 per turn and 12 in total.
- **Create your first blob:** with no blobs, the app shows that instead of a leftover conversation.

## Changed

- **Effort for OpenCode:** DeepSeek V4.1 Flash (and any OpenCode model that reports variants) now shows its real levels. Databases that were seeded with the control off are opened once.
- **Ultracode and dynamic workflows are on by default**, with an opt-out in Settings.
- **Message actions:** no backgrounds, centred beside the bubble (left of yours, right of the blob's), copy confirms with a check mark. One reaction per message, shown on the bubble's corner; click it to remove it.
- **Usage page:** plan limits first, orbs with the provider logo inside and the percentage below, card layout.
- **Header:** no divider; the conversation fades in beneath it and the logo, name, role and title sit on one line.
- **Effort selector:** the "High" label is no longer clipped; the Claude pixel effect always moves and only Max and Ultracode add colour.
- **Dialogs:** the icon sits beside the title.

## ChatGPT dictation

A live probe showed OpenAI's transcription endpoint answers third-party apps with a Cloudflare bot challenge. The Codex sign-in is fine; the request is blocked. Bloblex does not try to get around that. The message now says so, "ChatGPT when available" cools down for ten minutes after a failure, and the on-device model is downloaded first. **Use On this device for dictation.**

## Compatibility and data

- A blob's stored look may now carry an optional `bot` object (outline and three colours); it is validated and ignored while Bitbots is off. No table changes.
- One reaction per message: toggling collapses an older multi-reaction message to the one you pick.
- One settings key is written once (`migration.opencodeEffortGateOpened`).

## Verification

- Rust workspace excluding the desktop crate: 472 tests passed, 0 failed (run with `RUST_MIN_STACK=33554432`; one existing test overflows the default stack). Desktop crate library: 34 passed. Desktop UI: typecheck clean, 516 tests passed, production build.

Unverified: Bitbots in the native windows and companion, the leader's tools and OpenCode effort against live CLIs, the effect of OpenCode effort on provider behaviour, and clean-machine installation.

## Manual installation

Download `Bloblex_0.1.0-beta.20_x64-setup.exe` and verify it against `SHA256SUMS.txt`. The installer is unsigned (Windows may warn). No updater manifest is published; the signed `channel-beta` feed remains at beta.6. Install beta.20 manually over your current version.
