# Bloblex 0.1.0-beta.23

A fix-and-polish release for fresh installs. **Verified with unit tests, the
standard gates and a live probe of the OpenCode CLI on the machine it was built
on; the UI changes were checked in the browser preview, not in the installed
native windows.**

## Fixed

- **OpenCode 2 is no longer shown as "Sign-in status unknown".** OpenCode 2
  (checked against 2.0.28) prints its credentials as a whitespace-aligned row,
  `OpenCode Console  Default  stored`, and rejects `models --verbose`. Bloblex
  could parse neither, so a fresh install found the CLI but could not say
  whether anyone was signed in. The sign-in check now reads those rows, maps the
  Console and Zen names to the Zen gateway and Go to the Go gateway, and treats
  `stored` as signed in. Live result on the build machine: online, authenticated,
  no probe error.
- **The OpenCode version is read.** `opencode --version` prints `opencode
  v2.0.28`; the `v` stopped the number being recognised, so the version showed
  as unavailable.
- **A model listing is not claimed as a sign-in.** If neither the credential
  list nor the verbose listing answers, a plain `opencode models` run only
  reports an honest "unknown". The catalog lists gateway models whether or not a
  credential exists, so it is never presented as proof of sign-in.

## Changed

- **Effort picker.** The popover is wider when Ultracode is offered so all six
  levels fit, and Ultracode wears the same gradient as Max in every provider
  (Claude's top level used to be forced to a solid colour).
- **Claude model names carry their release.** "Sonnet" becomes "Sonnet 5.5"
  when the model id names the release (`claude-sonnet-5-5`), the way Codex names
  already do. If Claude Code reports only a bare alias, the name is unchanged.
- **Check marks sit in the centre of their boxes.** The launch checklist and the
  team menu drew their check, cross and bang as text glyphs, which font metrics
  never centre; they are now drawn shapes, in both themes.
- **Robot theme launch animation.** The ring spinner is replaced by a pixel cell
  chasing round a 2x2 grid, with a row of pixels that lights in a short run while
  Bloblex looks for coding agents. The normal theme is unchanged.

## Verification

- `bloblex-runtime`: 23 tests (7 new: v2 row parsing, display-name mapping, the
  calling path with fixture commands, a quiet unknown for unclassifiable rows and
  for a plain listing, and the `v`-prefixed version).
- Desktop: typecheck, 522 tests (2 new) and the production web build.
- Live on the build machine against OpenCode 2.0.28: `online`, `Authenticated`,
  `{opencode: Authenticated}`, no probe error.

Unverified: the sign-in label for the Go gateway (the Console row is mapped to
Zen, and the CLI does not say it also covers Go), OpenCode 2 releases other than
2.0.28, a machine with no OpenCode credentials (not tested; signing out was
outside this release's scope), the UI in the installed native windows, and
clean-machine installation.

## Manual installation

Download `Bloblex_0.1.0-beta.23_x64-setup.exe` and verify it against
`SHA256SUMS.txt`. The installer is unsigned (Windows may warn). No updater
manifest is published; the signed `channel-beta` feed remains at beta.6. Install
beta.23 manually over your current version.
