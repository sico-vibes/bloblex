# Bloblex 0.1.0-beta.2

Interface redesign.

## Changes

- Simpler main window: each blob in the sidebar shows its name, what it is doing or its latest conversation, and the time. Expanded blobs keep one highlight with their projects and conversations nested underneath.
- A profile button replaces the old runtime footer. Its menu holds Usage, Find coding agents, Settings and Quit, and Bloblex asks for your name on first run.
- The chat header shows only the blob and the conversation. The details panel shows one avatar, then plain details.
- Settings has three pages: General, Agents and Updates. Agents lists each coding tool found on this device with its blobs and approval settings.
- New dropdowns and one consistent look across the app.
- Blobs relax after finishing, go idle, and fall asleep after 10 minutes without activity.

## Known limits

- Unit tests use fake processes. Not yet verified against live provider command line tools or on a clean machine.
- The installer is not code-signed, so Windows may show a SmartScreen warning.
- Windows only. WSL launch is not usable yet.
