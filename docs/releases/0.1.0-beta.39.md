# Bitbots 0.1.0-beta.39

A large update after beta.38: the Manager works with its teammates more like a team, Bitbots recovers on its own when something stops, and two looks remain, Haze and Stone. If you run beta.32 or later, this version downloads by itself and shows **Restart to update** in the top bar.

## New

- **The Manager runs the team.** It assigns work to its teammates, follows each assignment on a card in its conversation, and reports back with **Checked:** or **Not done yet:** against what "done" meant. A teammate with nothing to report answers `(pass)`, and the card reads **Done, nothing to report**.
- **See what a bot is doing.** The sidebar, the companion and assignment cards say what is happening right now, such as **Running npm test** or **Editing App.tsx**. After a minute with nothing heard, they say **Waiting for Claude Code…**.
- **Always allow.** An approval card for a safe action inside the project offers **Always allow** next to Allow and Deny. The rule is saved for that bot only and never applies in Plan mode or to scheduled runs. See and remove saved rules in **Settings › Approvals**.
- **Health check.** **Settings › Health check** checks each coding agent, the database, the hook bridge, Remote and dictation, with a fix button where one exists.
- **Share a bot.** **Export** on a bot's page saves it with its look, instructions, approved notes, schedules and the skills it uses. Import it in **Settings › Backup**; its schedules arrive paused. Sign-ins, environment values and app settings are never included.
- **Watch Claude Code outside Bitbots (opt-in).** Turn it on in **Settings › General › Companion** to see Claude Code sessions you start in a terminal or editor in the companion's Activity pane: the folder and whether it is working, needs you or is done, never what you typed. Bitbots shows the exact change to Claude Code's settings first, backs the file up, and removes only its own entries when you turn it off.
- **Assignments on your phone.** A paired phone shows what the Manager's teammates are doing and, with chat access, can stop one.
- **Continue in another bot when a coding agent hits its limit.** The usage-limit notice offers **Continue in another bot…**, which lists bots on a different coding agent first and drafts a summary for you to send.

## Changed

- **Two looks: Haze and Stone.** The Frost look is retired, with its wallpapers and glass settings. A saved Frost choice moves to Haze. The 2D robot and the pixel icons are retired too; those bots now use the 3D robot and their coding agent's logo.
- **Safer schedules.** A run that only read things retries after 1, 5 and 15 minutes; one that changed files or ran commands is never retried on its own, and its card offers **Retry now**. A run that found nothing ends as **Nothing to report**.
- **Loop guards.** A bot cannot send work back to a bot that is waiting on it, and a teammate that failed twice in a row with the same error is not sent the same work a third time.
- **Faster start.** Older idle conversations load in the background after the window opens, instead of all at once.
- **Stopping a Manager turn also stops the assignments it started.**

## Fixed

- **The Bitbots service now restarts itself if it stops**, with growing waits, and says so in a banner. After five stops in two minutes it stops trying and offers **Try again**.
- **Messages waiting for a busy teammate survive a restart.**
- **A long command no longer gets its turn stopped for being quiet**, and a turn that is stopped says which coding agent went quiet and for how long.
- **Approvals for a bot proposal could fail** with "could not be done" when the model name did not match the catalogue.
- **Table headers broke words in the middle**, and message text could run under the conversation outline in narrow windows.

## Installation

Running beta.32 or later: wait for **Restart to update**, or check now in Settings › Updates. Older versions: download `Bitbots_0.1.0-beta.39_x64-setup.exe` and verify it against `SHA256SUMS.txt`. The installer is not Authenticode-signed (Windows may warn).
