# Bloblex 0.1.0-beta.14

## Changes

### Conversations
- Messages always appear in the order they happened. Previously a teammate's reply ("Message from X") could show above the leader's own message, because live updates arrived without a timestamp.
- Tool activity is hidden by default; you only see that a blob is working. Codex's empty reasoning steps no longer appear at all, and the remaining steps carry real names (the command, the tool, the search).
- New experimental setting, **Agent activity** (Settings → General → Experimental). It shows each reply's work as one line under it, for example "Ran 1 command · searched the web · edited 1 file". Open the line to see every step, and open a step to see the command and its output, the tool with its input and result, or the file and its diff.
- The conversation outline appears only when the conversation is long enough to scroll. It sits at the left edge beside the sidebar and stays faint until you hover it.
- The effort slider follows your pointer exactly while you hold it, and saves only when you let go.

### Companion
- One blob in focus, the rest in sight. The focused blob glows (pulsing while it works) and shows its last steps as a short ticker. Up to four teammates sit beside it in a 2×2 grid, each with its name and what it is doing.
- Teammates you pin come first, then those waiting for you, then the busy ones, then the most recent. "All blobs" lists every blob by project and lets you pin up to four to the island.
- Chat height is now a setting in the companion: Compact, Comfortable (default) or Tall.
- With Agent activity on, the Activity tab shows the focused blob's steps with their details.
- Better spacing between the permission badge and the header buttons. The companion's settings view now uses the taller island.

## Verification

- Download `Bloblex_0.1.0-beta.14_x64-setup.exe` (12,918,554 bytes; SHA-256 `d70826a1a6d7e2657a05923ca2a5c8ae05db6a4753657ec15d0ee2d8674f76c1`) and verify it against the attached `SHA256SUMS.txt`.
- It has no Windows Authenticode signature (`NotSigned`), Tauri updater signature, or updater manifest. The signed rolling `channel-beta` feed remains at beta.6.
- Windows may show a SmartScreen warning on first install. Install over the existing version to update; your blobs and conversations are kept.
