# Bloblex 0.1.0-beta.12

## Changes

- Add a floating dictation bubble that appears outside the app while dictation is active, adapted from the Waveora bubble without its logo. It shows a live waveform driven by the microphone level, a processing spinner, and an error state, and can be dragged or tapped to return to Bloblex.
- Add synthesized dictation cues — record start, processing start, processing finish, and error — ported from Waveora's Web Audio sound design. No audio assets are bundled.
- Show the bubble only while dictation is active and the companion is hidden. When the companion is visible, dictation turns it into a full-cover listening wave surface instead, so exactly one surface shows visuals and plays sounds.
- Retain beta.11's on-device dictation engine, Ctrl+E shortcut, on-first-use model download with SHA-256 verification, and Settings Speech model manager.

## Verification

- All 361 desktop tests, typecheck, and the production web build passed.
- The offline Rust workspace suite passed, including the `bloblex-speech` unit tests; the desktop crate type-checks with the `native` feature enabled.
- Live microphone capture, real model inference, and clean-machine installation remain unverified for this update.
