# Bitbots 0.1.0-beta.44

This release brings several big pieces at once: better approvals and settings, generated pictures, a review screen for changes, and using Bitbots across two Windows computers. If you run beta.32 or later, this version downloads by itself.

**After updating, the Claude Code and OpenCode usage bars stay blank until you turn on Settings › Read sign-ins for usage bars.** That setting is off until you choose it.

## Added

- **Two computers.** Settings › Machines links another Windows computer through Remote. Its bots appear in your sidebar under its name, and their conversations open read-only.
- **Take over.** Moves a conversation to the computer you're on, with its branch and a summary for the bot. Only one computer runs a conversation at a time. You can take it back the same way.
- **Shared project settings.** A `.bitbots.json` in a repository can hold a setup script, default bot and approval mode. It does nothing until you trust that exact file, and it can never turn on Full access.
- **A template for a new computer.** Settings › Backup exports your bots, skills and schedules with nothing secret. First run on a new computer can bring them in.
- **A review screen.** The rail's Review button shows every changed file with its whole diff, unified or side by side. Stage or discard per file, with Undo, and send line comments to the bot as one message.
- **Create PR opens the pull request itself** when the GitHub CLI is signed in, from a drafted title and description.
- **More ways to add a project.** New project gains Clone and Find. Project settings can copy listed files into each new task copy and set up submodules.
- **Leftover task copies.** Settings › Health check lists them. Only you can remove one.
- **Search.** `@` in the message box offers files, and Ctrl+Shift+F searches a project's contents.
- **Generated pictures** appear in the chat and the companion, from wherever the coding agent saved them.
- **Approval modes.** Auto-accept edits and Full access join Ask and Auto. A project can set its own approvals, models and setup script.
- **The companion** shows "Changes ready" and names the computer a bot is working on.

## Changed

- **OpenCode turns no longer stop at 30 minutes.** A long turn runs until it finishes.
- **Native Remote accepts a computer's name in any case.** Links by host name used to be refused.

## Not yet checked on real hardware

Machine links and Take over were tested with two copies of Bitbots on one computer, not on two real computers or over a real Tailscale certificate. Opening a real pull request hasn't been tried. Tell us what you find.

## Installation

Running beta.32 or later: wait for **Restart to update**, or check now in Settings › Updates. Older versions: download `Bitbots_0.1.0-beta.44_x64-setup.exe` and verify it against `SHA256SUMS.txt`.
