# Bloblex 0.1.0-beta.28

A layout fix release for beta.27. **No Rust code changed since beta.27; the
changes are styles and the composer's sizing. Layout was measured in the browser
preview at the minimum window width, not in the installed native windows.**

## Fixed

- **The send button was clipped to a sliver in the pixel-robot theme.** A beta.27
  change inserted a rule for the model pill's divider in the middle of the
  selector that styles the send and microphone buttons, so the send button became
  2 px wide. The selector is whole again. Measured at the narrowest window width:
  the send button is 32 px and fully inside the composer.
- **The composer no longer stays one line.** It grows with what you type, up to
  about 40% of the window height, and only then scrolls. The companion composer
  grows up to about six lines.
- **The companion composer is no longer cramped.** The message has its own
  full-width row and the model, effort, context, attach, microphone and send
  controls sit beneath it.
- **The companion's model menu is no longer cut off on the left.** The model and
  effort menus open from the left edge of their pill and stay inside the window.
- **The startup checklist is centred** under the animation instead of sitting to
  one side.

## Changed

- In the main composer the send button, microphone and context ring never shrink;
  the model and effort names truncate first. The Plan label collapses to its icon
  only when the composer is narrow, and the permission label ("Ask first", "Full
  access") collapses only when it is very narrow. Before, the permission label
  disappeared at any window under 940 px.

## Verification

- Desktop: typecheck and 553 tests pass.
- Measured in the preview at 860 px wide (the smallest window): composer strip has
  no overflow, send button 32 x 32 inside the box, permission label shown, Plan as
  an icon; typing 12 sentences grew the field from 30 px to 246 px; the companion
  input row is full width and its model menu opened inside the window.
- Rust workspace not re-run: no Rust source changed since beta.27 (520 tests passed
  there).

Unverified: the installed native windows, long model names in the companion
controls row, and a window narrower than 860 px.

## Manual installation

Download `Bloblex_0.1.0-beta.28_x64-setup.exe` and verify it against
`SHA256SUMS.txt`. The installer is unsigned (Windows may warn). No updater
manifest is published; the signed `channel-beta` feed remains at beta.6. Install
beta.28 manually over your current version.
