# Glossary

> **What this is:** the words Bitbots uses in the app, in the sense the app uses them.
> **Status:** current; written for v0.1.0-beta.35
> **Last updated:** 2026-10-19

| Term | Meaning |
| --- | --- |
| **Bitbots** | The app, and the default look. |
| **bot** | One saved character: a name, colour, art, instructions, and the coding agent, model and permission settings it uses. A bot can own many conversations. |
| **Manager** | The one permanent bot that works across every project. It plans with you and proposes changes; it creates nothing without your approval. |
| **companion** | The small floating window that shows bot state, approvals, questions and a compact chat. |
| **look** | A visual style for the whole app: Bitbots (Frost), Blobots, Legacy, Pop or Dot. |
| **Frost** | The design of the Bitbots look: flat translucent panels over a wallpaper, hairlines and rounded rectangles. |
| **art** | A bot's drawing style: 3D robot, Flat robot, Pop robot, Dot robot, Glossy blob or Hand-painted. Art is chosen per bot and is separate from the app look. |
| **orb** | The small illustration that represents a look in Settings and onboarding. It is not a screenshot and does not animate. |
| **wallpaper** | A Frost background: Lake, Dusk, Bloom, Sand or your own image. |
| **glass** | A Frost translucency level: Solid, Balanced or Clear. |
| **density** | Row spacing: Compact, Default or Roomy. |
| **coding agent** | An installed command-line tool Bitbots can drive: Claude Code, Codex or OpenCode. |
| **runtime** | The coding agent an individual bot or conversation is set to use, as shown in the details panel. |
| **conversation** | One thread with a coding agent, with its own history and settings. |
| **turn** | One prompt and the work that follows, ending as completed, failed or cancelled. |
| **project** | A named folder, with an optional description and tags, that bots and conversations can work in. |
| **team** | The bots and projects shown together in the sidebar, with roles and tags. |
| **side conversation** | A conversation between two bots, with its own history and a link back to the conversation that started it. |
| **approval mode** | How permission requests are answered: Ask first, Auto, or Full access. |
| **permission request** | A coding agent's question about one action: a command, an edit, a network call or a tool. |
| **proposal** | A change the Manager wants to make, held until you approve it. |
| **automation** | A saved prompt that runs on a schedule. |
| **memory** | A durable note for a bot, a project or everyone. |
| **skill** | A folder of instructions and files a bot can load when it needs them. |
| **prompt queue** | Prompts stored for a conversation, sent after the current turn, at a set time, or when you ask. |
| **steer** | Sending guidance into a running turn instead of waiting to send a new prompt. |
| **Limited** | A conversation whose coding agent has run out of its usage window; it shows the reset time when the agent gives one. |
| **Remote** | Access to your bots from a paired phone or another computer. Off by default. |
| **tier** | What a paired device may do: viewer, chat or operator. |
| **Tailscale** | The Remote method that keeps the connection inside your own Tailscale network. |
| **Native** | The Remote method that serves a secure address from this computer. Also called Direct in the app. |
