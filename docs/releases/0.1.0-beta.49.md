# Bitbots 0.1.0-beta.49

This release is about speed again, and it fixes the biggest cause found so far. If you run beta.32 or later, this version downloads by itself.

## Changed

- Opening a conversation should be much faster. A slow lookup that got worse with a long history is fixed.
- The app should start much faster. It loads a summary of your conversations at startup and loads each one when you open it, instead of loading all of them in the background.
- Saving a setting should no longer wait while conversations load.
- Changing effort should show the new level as soon as you pick it. If the save is refused, it goes back and shows the reason. It should also no longer wait on the provider's model list when one is already known.
- A task you assign should show as Starting on the bot's lane straight away.
- Long replies and conversations with a lot of tool output can still feel heavy. More work on this is coming.

## Installation

Running beta.32 or later: wait for **Restart to update**, or check now in Settings › Updates. Older versions: download `Bitbots_0.1.0-beta.49_x64-setup.exe` and verify it against `SHA256SUMS.txt`.
