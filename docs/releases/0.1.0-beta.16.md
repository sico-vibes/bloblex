# Bloblex 0.1.0-beta.16

## Changes

- Fix Close chat reopening a side conversation when the companion is visible. Closing returns to the original conversation, and selecting another conversation clears the side view.
- Check coding agents concurrently at startup, remove the permanent failed-probe cache, and retry failed discovery in the background after 3, 10 and 30 seconds. The banner shows retry progress and clears after recovery.
- Settings → Agents shows the failed check, its time and safe error details. Scan again shows a spinner, Scanning status and the result. Find coding agents now lives here; its quick-switcher action opens this page and scans.
- Replace the Codex logo with the gradient Codex cloud and white terminal mark, sized consistently with the other provider logos.

Seven new features are available in Settings → General → Experimental. Each is off by default:

- **Change review:** saved file changes appear below the reply, with a diff, addition/deletion counts, Keep and Revert. Revert asks for confirmation and reverses only that saved single-file patch; incomplete patches, unsafe paths and conflicting later edits are refused.
- **Message actions:** Copy, Retry as a new prompt and Edit as a new draft. Existing history is preserved.
- **Search all conversations:** search saved, active conversations through the quick switcher, then open a result at its message. Archived conversations are excluded; results are limited to 50.
- **Automatic titles:** name a main conversation from its first prompt, preserving custom titles and side-conversation topics.
- **Undo:** undo blob archiving or conversation deletion for eight seconds. Conversation deletion is queued durably by the daemon; closing a window does not cancel it, and quitting finishes pending deletions.
- **Shortcut sheet:** Ctrl+/ and the profile menu open the keyboard shortcut list.
- **Approval badge:** show a waiting-blob count on the Windows taskbar and in the tray tooltip.

The daemon's Git commands hide their console windows on Windows, and file paths in change-review cards align to the left.

## Manual installation

This follows the recent manual-install beta releases. Download `Bloblex_0.1.0-beta.16_x64-setup.exe` (13,145,402 bytes; SHA-256 `cbdef090e7011743ba020bf899d6768c9a9624c007170f2d7a41a3f24aec4828`) and verify it against the attached `SHA256SUMS.txt`. Install over the existing version to update while retaining your blobs and conversations.

The installer is unsigned (`NotSigned`). No Tauri updater signature or manifest is published; the signed rolling `channel-beta` feed remains at beta.6, so install beta.16 manually.
