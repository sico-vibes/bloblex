# Bloblex 0.1.0-beta.5

## Changes

- A new launch intro runs startup checks for the Bloblex service, installed coding agents, sign-in, model lists, and usage data, and reports any issues it finds.
- The companion is off by default. Open it from the sidebar switch, or turn on **Open at startup** in settings.
- First-run onboarding now has three steps: choose a local name, find or install an agent and sign in (with commands and help links), then create your first blob.
- Give each blob an outfit from its wardrobe, or choose **Auto** to follow the season.
- OpenCode Go models are included in the model list. Usage & limits now lists 150 models with official price sources and applicable tiers. Free prices are labelled as free; unknown prices stay unknown rather than appearing as zero.
- The database upgrades to schema 8, automatically creating and verifying a backup before migration.

## Known limits

- This build is not code-signed. It has not had native-window or live-provider verification.
- Existing companion users: the companion no longer opens automatically unless the new **Open at startup** setting is on.
- Cost budgets are not offered yet.
- The official price list was checked on 2026-10-04; check the sources again when vendors change prices.
