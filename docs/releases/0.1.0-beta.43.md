# Bitbots 0.1.0-beta.43

This release finishes bots across projects: you build a few good bots once, and each one works in any project, one conversation at a time. If you run beta.32 or later, this version downloads by itself and shows **Restart to update** in the top bar.

## Added

- **A conversation has its own project.** **New conversation** can start in any project, or in **No project**, which uses the bot's private folder. The bot gets that project's instructions, memory and folder, whatever its default project is.
- **Project instructions from the repository.** If a project's folder has a `.bitbots.json` with an `instructions` text, a bot working there reads it, up to 4,000 characters.
- **Approvals for one project or every project.** When a conversation is in a project, its approval card offers **Always in** that project or **Always, every project**. Settings › Approvals shows where each saved approval applies, and you can change it there.
- **Hand work over in any project.** Any bot can now be given work in any project. Unless a project is named, the work opens in the project of the conversation it came from.
- **The companion shows the project.** Its conversation picker groups by project, and the pill names the project while a bot is working in it.
- **The Bitbots MCP knows about projects.** `send_message` can start a conversation in a project, and `list_conversations` shows each conversation's project and can filter by it. `list_projects` now also lists bots that have conversations in a project.

## Changed

- **A new conversation opens where you were working.** With no project chosen, it opens in the project of the bot's latest conversation, then its default project, then its private folder.
- **A bot's default project is only a default.** A bot can no longer be refused work because it "belongs to another project".
- **Deleting a project** also removes approvals saved only for it. Its conversations stay, under **No project**, and the folder on disk isn't touched.

Approvals you saved before this version still apply in every project, as they always did.

## Installation

Running beta.32 or later: wait for **Restart to update**, or check now in Settings › Updates. Older versions: download `Bitbots_0.1.0-beta.43_x64-setup.exe` and verify it against `SHA256SUMS.txt`. The installer is not Authenticode-signed (Windows may warn).
